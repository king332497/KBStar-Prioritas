KBstar Studio — Admin Panel Prototipe Independen v78

MENJALANKAN DI WINDOWS
1. Gunakan Node.js 22 atau lebih baru.
2. Ekstrak seluruh ZIP ke satu folder.
3. Klik dua kali MULAI-ADMIN.cmd.
4. Pada penggunaan pertama, buat nama admin dan sandi minimal 12 karakter. Sandi tidak ditampilkan saat diketik, dan disimpan hanya sebagai hash scrypt.
5. Buka http://127.0.0.1:8787 untuk prototipe pengguna.
6. Buka http://127.0.0.1:8787/admin untuk panel admin.
7. Biarkan jendela server terbuka. Ctrl+C menghentikan server.

Tidak ada nama admin, kata sandi, ataupun pengguna aktif bawaan. Akun pada screenshot adalah sesi pengujian yang benar-benar dihubungkan selama QA.
Membuka index.html langsung tanpa server tetap membuka prototipe, tetapi tidak mengaktifkan layanan admin.

LINTAS PERANGKAT / HP
Server bawaan hanya mendengarkan localhost. iPhone/Android belum diuji fisik dan layanan belum dipublikasikan.
Untuk akses lintas perangkat, operator perlu hostname yang bisa dijangkau dan sertifikat HTTPS yang dipercaya perangkat.
Set HOST (contoh 0.0.0.0), PORT, HTTPS_CERT, dan HTTPS_KEY pada lingkungan server. Server menolak bind non-localhost tanpa konfigurasi HTTPS.
Jangan membuka server HTTP tanpa TLS ke internet. Penyiapan hosting/domain bukan bagian paket ini.

DATA DAN KONTROL
- ID sesi acak dibuat oleh server untuk setiap pembukaan dokumen. Refresh membuat sesi baru; sesi lama akan menjadi offline/terputus.
- Nama adalah isian pengguna, belum diverifikasi. Tidak ada autentikasi akun bank nyata dalam prototipe ini.
- Tidak ada pelacakan lintas browser/perangkat atau penggabungan sesi berdasarkan nama.
- Data pemantauan: ID, nama isian, halaman, waktu aktivitas/status, dan daftar tujuan yang diizinkan oleh alur simulasi.
- Tidak mengirim password pengguna, kode, PIN, NIK, rekening, dokumen, atau data finansial ke panel admin.
- User diberi pemberitahuan singkat bahwa sesi prototipe dipantau admin pendamping.
- Navigasi: pembuka pinjaman, login, verifikasi, kode simulasi, data pengajuan, dokumen, informasi pinjaman, rekening, persetujuan.
- Tujuan hanya tersedia jika pernah dibuka dalam dokumen yang sama dan syarat alur masih terpenuhi. Syarat diperiksa lagi pada perangkat sebelum penerapan.
- Analisis, Dashboard, Transfer, Akun, Produk, Menu, Notifikasi dipantau; kontrol pindah halaman dari area tersebut belum diaktifkan agar tidak memotong prosesnya.
- Saat PIN/pemrosesan/transisi terbuka, arahan ditolak atau dinonaktifkan.
- Dikirim tidak sama dengan Diterapkan. Diterapkan menunggu konfirmasi halaman dari perangkat pengguna.
- Perintah berlaku 15 detik; tidak dikirim sebagai arahan baru setelah kedaluwarsa.
- ID permintaan mencegah pengulangan perintah yang sama selama sesi tersimpan.
- Admin tunggal memiliki akses seluruh sesi prototipe servernya. Multi-organisasi dan role bertingkat belum tersedia.

PENYIMPANAN
Akun admin: data/admin.json (hash sandi, bukan sandi mentah).
Audit: data/audit.jsonl; hanya server yang dapat mengaksesnya melalui rute yang tersedia. Simpan direktori ini di media server yang terlindungi.
Sesi/token admin dan pengguna bersifat sementara di memori; restart server meminta login ulang dan membuat koneksi pengguna baru. Arahan tertunda sebelum restart dicatat kedaluwarsa.
Panel menampilkan maksimal 100 peristiwa audit terkini; file audit tetap berisi seluruh catatan. Tetapkan retensi/rotasi sesuai kebutuhan sebelum hosting publik.
Sesi yang tidak memberi kabar 24 jam dihapus dari memori. Tidak ada backup otomatis direktori data dalam paket.
